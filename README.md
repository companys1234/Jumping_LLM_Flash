# Jumping-LLM-Flash
Jumping-LLM-Flash - библиотека для быстрой сборки маленьких языковых моделей, с фокусом на оптимизацию обучения, инференса, и работы с данными.
А также на уменьшение количества кода для построения полного пайплайна.благодаря этой библиотеке вы можете быстро собирать прототипы языковых моделей, для эксперементов 


Jumping-LLM-Flash is a library for quickly building small language models, focusing on optimizing training, inference, and data manipulation.
It also aims to reduce the amount of code needed to build a complete pipeline.With this library you can quickly build prototypes of language models for experimentation.
